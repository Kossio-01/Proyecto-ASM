# Proyecto-ASM
# 🌊 Cuidando Nuestros Ríos – Río Pance

Este proyecto forma parte de la materia Arquitectura de Sistemas Multimedia (ASM) de la Universidad Autónoma de Occidente (UAO).

El objetivo es diseñar y prototipar una aplicación web adaptativa que promueva la conciencia ciudadana y el cuidado del Río Pance, uno de los ríos más representativos de Santiago de Cali.

# El sistema permitirá:

📌 Gestionar actividades relacionadas con el cuidado del río (agregar, eliminar y marcar como realizadas).

🎥 Mostrar videos e infografías con información sobre la historia, características y problemáticas del Río Pance.

🎧 Ofrecer una biblioteca multimedia (audio, video e imágenes) que fomente la conexión emocional con el entorno natural.
